## Steps to automate build using github actions for spring boot microservices ##
1. Login to docker.io -> generate access token Personal access tokens -> New access token (with read & write)
2. provide docker file in every services
Each service → its own Docker image → GitHub Actions builds → push → deploy to Render

Example (order-service/Dockerfile):

		FROM eclipse-temurin:17-jdk-alpine
		WORKDIR /app
		COPY target/*.jar app.jar
		ENTRYPOINT ["java","-jar","app.jar"]
		
3. Build JARs (multi-module Maven)
	mvn clean package -DskipTests
	
4. GitHub Actions (build + push images)

Create:

.github/workflows/deploy.yml

5. name: Build & Push Microservices

on:
  push:
    branches: [ "main" ]

jobs:
  build:
    runs-on: ubuntu-latest

    strategy:
      matrix:
        service: [config-server, service-registry, api-gateway, order-service, user-service]

    steps:
      - uses: actions/checkout@v3

      - name: Set up Java
        uses: actions/setup-java@v3
        with:
          distribution: 'temurin'
          java-version: '17'

      - name: Build JAR
        run: mvn -pl ${{ matrix.service }} -am clean package -DskipTests

      - name: Login to Docker Hub
        run: echo "${{ secrets.DOCKER_PASSWORD }}" | docker login -u "${{ secrets.DOCKER_USERNAME }}" --password-stdin

      - name: Build Image
        run: docker build -t ${{ secrets.DOCKER_USERNAME }}/${{ matrix.service }}:latest ./${{ matrix.service }}

      - name: Push Image
        run: docker push ${{ secrets.DOCKER_USERNAME }}/${{ matrix.service }}:latest
		
6. Add secrets in GitHub

Go to:
Repo → Settings → Secrets

Add:

DOCKER_USERNAME
DOCKER_PASSWORD

(for Docker Hub)

7. 6. Deploy to Render

Render does NOT run docker-compose for multiple services in one go.

👉 You must create separate services.
